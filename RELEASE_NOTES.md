# splitd v3.0.0

This release contains the Linux amd64 V3 binary. The repository includes the Iran and foreign installers, sample configurations, and source code. Configure both endpoints with matching flow ports and `FLOW_STALE_SEC` before starting a test deployment. See `README.md` for setup and validation guidance.

V3 is not wire-compatible with V2. This build has not been validated on your production route; begin with a test instance.
